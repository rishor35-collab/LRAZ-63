# LRAZ63 Performance OS — Luxury Prototype

Responsive React + Vite prototype based on your supplied design reference.

## Start online (no installation)
1. Create a free GitHub repository and upload the **contents** of this folder (not the ZIP itself).
2. Open `https://stackblitz.com/github/YOUR_USERNAME/YOUR_REPOSITORY` (public repository required for this direct URL). Alternatively import the repository into CodeSandbox.
3. Run `npm install` and `npm run dev` if the online editor does not start automatically.
4. Open Preview.

## What works
- Responsive dashboard and navigation
- Workouts, meals, body-weight, and goals entry
- Six selectable themes
- Demo backup export and restore (only this starter format)
- Data persists in the current browser's localStorage
- Uploaded original gym images included under `public/images`

## What is NOT implemented
- Cloud sync, user accounts, Supabase, real steps/sleep integration, barcode or AI food scanning, exercise video library, community backend, Base44 export import.
- Dashboard macro, step, sleep and trend illustrations are samples and are labelled as such.
- Do not deploy as a production health-data service until authentication, database security, privacy handling and testing are completed.

## Independent code
No Base44 SDK, Bolt or paid AI integration.
